# Архитектура клиента

Клиент построен из Gradle-модулей Kotlin Multiplatform. Общий интерфейс использует
Compose Multiplatform; разрешения, системные службы и другие возможности ОС реализуются
в платформенных source sets.

```text
androidApp / iosApp / desktopApp   — приложения платформ
shared-ui                        — оболочка, навигация и DI
feature-auth                     — вход
feature-chats                    — список чатов
feature-conversation             — переписка
feature-profile                  — профиль и настройки
feature-groups                   — группы
feature-admin                    — администрирование
shared-domain                    — модели и интерфейсы
shared-data                      — сеть, база данных, репозитории
core-runtime                     — сессия и жизненный цикл соединения
core-ui                          — общие UI-компоненты и ресурсы
build-logic                      — правила сборки и границы модулей
ci                               — проверки и сборка установщиков
```

Это описание структуры, а не опубликованное дерево исходников.

## Слои и состояние

Feature-модули содержат экраны и ViewModel. Они используют модели и интерфейсы
`shared-domain`, а также компоненты `core-ui`. Реализации репозиториев находятся в
`shared-data`; зависимости собираются в `shared-ui` через Koin.

Состояние передаётся через Coroutines и Flow. История переписки читается из Room.
Репозиторий получает серверные изменения и сохраняет их в базе; наблюдающий за ней
интерфейс обновляется автоматически. Отправка сообщений использует локальную очередь,
история загружается страницами. Кэширование истории не означает офлайн-доступность
всех административных операций или всех вложений.

`core-runtime` владеет авторизованной сессией и соединением. Экран наблюдает состояние,
но не создаёт отдельный WebSocket на каждый переход.

## Платформы

- `commonMain`: общий Kotlin-код и общий Compose-интерфейс.
- `androidMain`: интеграции Android, включая foreground-службу.
- `iosMain`: интеграции iOS; приложение запускается из Swift-хоста.
- `desktopMain`: JVM-реализации для Windows, macOS и Linux.

Наличие платформенного исходного кода не означает, что каждый сценарий уже прошёл
проверку на устройстве. Опубликованные установщики и ограничения указаны в Releases.

## Основные библиотеки

| Назначение | Технологии |
|---|---|
| Интерфейс | Compose Multiplatform, Material 3 |
| Состояние и навигация | Lifecycle ViewModel, Coroutines / Flow, Navigation 3 |
| DI | Koin |
| Сеть | Ktor, WebSocket, kotlinx.serialization |
| Хранение | Room Multiplatform, SQLite |
| Android-медиа | Coil, CameraX, Media3 |

Общий код компилируется для выбранных targets. Платформенные типы и ресурсы остаются
за соответствующими границами; допустимые зависимости модулей проверяются правилами сборки.
