# Куку! / Kuku!

Мессенджер на Kotlin Multiplatform и Compose Multiplatform для личных и групповых чатов.
Этот публичный репозиторий содержит описание проекта и установочные файлы. Исходный код
клиента развивается в отдельном закрытом репозитории.

## Скачать

- [Последний релиз](https://github.com/AMainActivity/kuku/releases/latest)
- [Все версии и списки изменений](https://github.com/AMainActivity/kuku/releases)

| Платформа | Файл |
|---|---|
| Android | APK для установки; AAB предназначен для публикации в магазине |
| Windows x64 | MSI |
| macOS Apple Silicon | DMG |
| Linux x64 | DEB |

Java входит в Desktop-пакеты. Подпись Desktop-пакетов и нотариализация macOS пока не настроены.
iOS-клиент разрабатывается в общей кодовой базе; публичного установочного пакета iOS здесь нет.
Контрольные суммы файлов находятся в `SHA256SUMS.txt` соответствующего релиза.

Автоматические архивы GitHub **Source code** содержат только файлы этого публичного репозитория,
а не исходники приложения. Для установки выбирайте APK, MSI, DMG или DEB.

## Возможности

- Вход по email-коду, профиль пользователя и управление сессиями.
- Личные и групповые чаты, ответы на сообщения и вложения.
- Локальная история, черновики и очередь отправки при отсутствии сети.
- Оперативные обновления через WebSocket и восстановление соединения.
- Две панели в широком окне: список чатов и переписка.
- На Desktop: Enter отправляет сообщение, Shift+Enter добавляет строку.

Для обмена сообщениями нужен совместимый сервер. Доступ к нему выдаёт его администратор.
На Android авторизованное соединение поддерживает foreground-служба.
Уже сохранённую историю можно просматривать без сети; не все служебные экраны и файлы доступны офлайн.

Звонки находятся в разработке и пока не заявлены как готовая возможность опубликованных версий.

Об ошибках можно сообщать в [Issues](https://github.com/AMainActivity/kuku/issues).
